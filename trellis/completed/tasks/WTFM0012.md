# WTFM0012 — Generate and check portable documentation discovery metadata

## Scope

- Add a public reusable discovery helper and opt-in Eleventy plugin configuration with a production origin, exclusions, and strict mode.
- Derive deterministic sitemap URLs from final HTML results, excluding noindex, redirects, 404s, internal output and noncanonical pages; generate robots.txt with the production sitemap reference.
- Check declared homepage icon URLs against real built image assets, allow a declared icon without a root favicon.ico, and diagnose missing/malformed local files without remote fetching.
- Surface actionable diagnostics; invalid supplied declarations fail, and missing recommended metadata warns by default and fails in strict mode.
- Exercise the feature in WTFM's own portable docs build and document ownership: Taproot managed rendering supplies its own discovery metadata; exact publication preserves producer files.
- Additive public API, minor version release. Coordinate with Espalier ESP0207 (independent immediate fix) and Taproot TR00812 exact-docs discovery validation.

## Acceptance and verification

- Build integration invokes the helper on final rendered output; off means unchanged legacy behavior.
- Tests use real output files and broken fixtures for missing icons, mismatched image bytes/types, noindex, canonical aliases, metadata comments, paths, exclusions, and deterministic escaped URLs.
- npm test, npm run build, portable docs build/validation, and Trellis check pass.
- No brand asset changes or dependency on untracked assets/.

## Risks

Use only local output files during checks. Production origin must be explicit and stable; staging is not required to be indexable. Do not invent modification dates or include generator-internal HTML fragments.

## Completed

Added the opt-in discovery helper, plugin integration, strict profile, package export and public docs in 0.17.0. WTFM's portable build now produces deterministic sitemap and robots files and verifies its declared icon. The managed artifact remains independently valid.

Verification: 447 tests passed; package build, actual docs build, and released artifact validator passed. The real docs test checks all nine sitemap routes against output files and compares two builds. Independent review found no defects in the WTFM changes. Coordinated work: Espalier ESP0207 and Taproot TR00812. Release and downstream adoption follow the normal publish-on-version-bump workflow; no production publication was performed here.

Follow-up review: ignore template/noscript/textarea metadata, decode HTML attribute entities, accept SVG export comments/DOCTYPE prologs, and distinguish invalid bytes from extension/type mismatches. Added regressions for these cases and documented and enforced that discovery requires full (not incremental) Eleventy results before output access.
